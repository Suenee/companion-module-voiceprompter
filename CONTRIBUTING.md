# Contributing

- Keep VPP behavior synchronized with `PROTOCOL.md`.
- Do not silently accept unknown deterministic call methods or parameters.
- Preserve automatic reconnect and API-key behavior.
- Update CHANGELOG for user-visible changes.
- Keep the temporary raw `JSON` action clearly separated from production protocol validation.
- Test both VP→BC parsing and BC→VP actions before merging.

Use feature branches and pull requests for non-trivial changes while the project matures.
